Super Store Sales & Profit Dashboard | Power BI
📊 Project Overview

This project presents an interactive Super Store Dashboard developed using Microsoft Power BI to analyze sales performance, profit, quantity, and product details. The dashboard transforms raw Superstore dataset records into meaningful visual insights to support data-driven decision-making.
